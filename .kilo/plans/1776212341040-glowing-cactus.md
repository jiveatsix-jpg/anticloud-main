# Plan: Sistema de Undo/Redo

## Objetivo
Implementar un sistema de undo (Ctrl+Z) y redo (Ctrl+Shift+Z) con historial de hasta 10 acciones para todas las modificaciones en la pizarra.

## Análisis del Sistema Actual
- **Estado principal:** `boards` (array de Board) se gestiona en `useBoards` hook
- **Cambios posibles:** 
  - Añadir elemento (`handleAddItem`)
  - Actualizar elemento (`handleUpdateItem`)
  - Eliminar elemento (`handleDeleteItem`)
  - Mover elemento (dentro de `handleUpdateItem`)
  - Duplicar elemento (`handleDuplicateItem`)
  - Reordenar capas (`handleReorderItem`)
  - Cambios de configuración del board

## Plan de Implementación

### 1. Crear hook `useHistory`
- Located: `hooks/useHistory.ts`
- Estado interno: `history` (array de estados anteriores de boards)
- Estado interno: `historyIndex` (índice actual)
- Constante: `MAX_HISTORY = 10`
- Funciones:
  - `pushHistory(newBoards)`: guarda el estado actual
  - `undo()`: devuelve al estado anterior
  - `redo()`: avanza al siguiente estado
  - `canUndo`: boolean
  - `canRedo`: boolean

### 2. Modificar `useBoards`
- Integrar `useHistory` dentro de `useBoards`
- Interceptar `setBoards` para guardar historial antes de cada cambio
- Asegurar que el historial solo guarde cambios significativos (no cada frame de drag)

### 3. Añadir keyboard listeners en App.tsx
- Ctrl+Z → `undo()`
- Ctrl+Shift+Z → `redo()`
- Verificar que no interfiera con otros inputs (input/textarea)

## Consideraciones
- **Rendimiento:** No guardar historial en movimientos continuos (drag), solo al soltar
- **Memoria:** Limitar a 10 estados para mantener control de memoria
- **Integración:** Necesita access a `setBoards` desde el hook de historial
