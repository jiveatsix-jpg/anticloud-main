# Plan: Sistema de Undo/Redo - Implementación Correcta

## Lógica Requerida (del usuario)

1. **Historial de acciones**: máximo 10 acciones guardadas
2. **Al hacer una acción nueva**:
   - Si el historial está lleno (10 acciones), eliminar la más antigua (índice 0)
   - Desplazar las demás hacia el principio
   - Añadir la nueva acción al final
3. **Ctrl+Z**: Retroceder una posición en el historial (índice - 1)
4. **Ctrl+Shift+Z**: Avanzar una posición (índice + 1)
5. **Verificar límites**: No permitir índices menores a 0 ni mayores a longitud-1

## Problema Actual

El bug reportado indica que al pulsar Ctrl+Z "no pasa nada" inicialmente, pero después de varias pulsaciones "desaparecen todos los elementos". Esto sugiere que:
- O el historial no se está guardando correctamente
- O `undo` está devolviendo el estado incorrecto (probablemente un estado vacío o muy antiguo)
- O hay un problema de closures donde `undo` accede a un estado stale del historial

## Análisis del Bug

### Posible causa raíz
En `useHistory.ts`, la función `undo` accede a `historyRef.current` que se actualiza en el renderizado siguiente, no inmediatamente después de `setHistory`.

```typescript
const undo = useCallback(() => {
  const currentIndex = historyIndexRef.current;
  const currentHistory = historyRef.current; // Puede ser stale!
  
  if (currentIndex > 0) {
    const prevIndex = currentIndex - 1;
    setHistoryIndex(prevIndex);
    return currentHistory[prevIndex]; // Devuelve valor stale
  }
  return null;
}, []);
```
